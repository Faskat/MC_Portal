# MC_Portal

Статус: хранилище бинарного артефакта `MC_Portal.exe`, без исходников проекта,
описания зависимостей и воспроизводимой сборки.

Файл имеет формат Windows-программы. Назначение, минимальная версия Windows
и порядок использования в репозитории не документированы; проверенного
скриншота интерфейса нет. Доступность EXE не означает, что функциональность
или совместимость подтверждены.

Для дальнейшего развития нужны исходники, инструкция сборки и описание
поведения. Статистику этого репозитория следует считать отдельно от исходного кода.
